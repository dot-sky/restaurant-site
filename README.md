# Vitalicious Restaurant Site

Restaurant site with pages using ES6 modules of JavaScript.

## Description

The site containes 3 pages: 'Home', 'Menu' and 'About Us', the content of the pages are created with JavaScript.

To navigate the site, events are binded to the buttons of the navigation bar, when one of the events is fired the content of the corresponding is added to the content container.

Each page is a separate module, and all of the modules are imported on the main file 'index.js' where the logic to load the pages dynamically is written.
